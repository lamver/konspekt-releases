# Konspekt

Умный блокнот для встреч. Записывает разговор, расшифровывает его и
превращает ваши обрывочные пометки в связное саммари. Всё считается на
вашем компьютере: аудио и транскрипт никуда не уходят.

Здесь лежат готовые сборки и обсуждения. Исходный код в отдельном
репозитории.

## Скачать

Windows 10 и 11, 64 бита: последняя версия на странице
[Releases](https://github.com/lamver/konspekt-releases/releases/latest).

Скачайте `konspekt-X.Y.Z-setup.exe` и запустите. Права администратора не
нужны, программа ставится в профиль пользователя.

## Почему Windows ругается на установщик

При первом запуске SmartScreen покажет синее окно «Windows защитила ваш
компьютер». Это происходит с любой программой без дорогой подписи
издателя, а не только с нашей. Нажмите «Подробнее» → «Выполнить в любом
случае».

Мы понимаем, что просить об этом неловко: Konspekt пишет микрофон,
слушает системный звук и перехватывает горячие клавиши, то есть делает
ровно то же, что и шпионская программа. Поэтому мы не просим верить нам
на слово и выкладываем внешние доказательства к каждому релизу.

### Как проверить сборку самому

**Отчёт антивирусов.** К каждому релизу приложена ссылка на VirusTotal.
Публикуем её с любым результатом: сборки PyInstaller регулярно ловят
несколько ложных срабатываний, и честное объяснение вызывает больше
доверия, чем отсутствие ссылки.

**Откуда взялся файл.** GitHub подписывает происхождение сборки. Команда
ниже проверяет, что установщик собран нашим публичным workflow из нашего
кода, а не собран кем-то другим и подложен:

```
gh attestation verify konspekt-0.1.0-setup.exe --owner lamver
```

**Контрольная сумма.** В релизе лежит `SHA256SUMS`. Сравните с тем, что
скачали:

```
certutil -hashfile konspekt-0.1.0-setup.exe SHA256
```

## Что программа отправляет в интернет

По умолчанию — почти ничего.

| Что | Когда | Можно отключить |
| --- | --- | --- |
| Проверка новой версии | Раз в сутки, запрос за `latest.json` в этом репозитории | да, в настройках |
| Скачивание моделей | Один раз, при первом запуске распознавания | скачиваются вручную |

Запись, расшифровка, определение говорящих и локальная модель для
саммари работают целиком на вашем компьютере, в том числе без интернета.
Аудио и транскрипты не отправляются никуда и никогда.

Если вы сами подключите чужого провайдера LLM по ключу, текст встречи
будет уходить к нему. Это ваш осознанный выбор, и по умолчанию так не
настроено.

## Сколько стоит

Запись, расшифровка, определение говорящих, локальные модели, экспорт и
удаление данных бесплатны всегда и без ограничений.

Платная только работа с чужим провайдером LLM по вашему ключу. Мы берём
деньги не за программу, а за удобство ухода к внешнему сервису.

## Что нужно от компьютера

- Windows 10 или 11, 64 бита
- 8 ГБ памяти для расшифровки, 16 ГБ для локальной модели саммари
- Около 2 ГБ на диске вместе с моделями

## Что-то сломалось

Заводите issue в этом репозитории. Приложите версию программы из раздела
«О программе» и, если можно, файл журнала: он лежит в
`%LOCALAPPDATA%\Konspekt\konspekt.log`.

Аудио и транскрипты к issue прикладывать не нужно, они нам не требуются.
