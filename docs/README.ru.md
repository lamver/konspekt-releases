## Нашли ошибку?

Заведите issue в этом репозитории. Приложите:
1. Версию программы из раздела «О программе»
2. Файл журнала по пути: `%LOCALAPPDATA%\Konspekt\konspekt.log`

**НЕ** прикладывайте аудио, транскрипты или заметки. Они нам никогда не нужны для отладки.
