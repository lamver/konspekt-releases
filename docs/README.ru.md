## Что нужно

Windows 10 или 11, 64-разрядная.

|           | Минимум | Спокойно |
| --------- | ------- | -------- |
| Процессор | 2 ядра  | 4 ядра   |
| Память    | 4 ГБ    | 8 ГБ     |
| Диск      | 1 ГБ    | 4 ГБ     |

Всё считается на процессоре, видеокарта не нужна. Распознавание
успевает с запасом: даже на одном ядре речь разбирается впятеро
быстрее, чем люди говорят.

Место на диске уходит в основном на модели, они скачиваются при первом
запуске: 214 МБ для распознавания речи и ещё около 1.8 ГБ, если нужны
заметки, которые пишет встроенная языковая модель.

## Нашли ошибку?

Заведите issue в этом репозитории. Приложите:
1. Версию программы из раздела «О программе»
2. Файл журнала по пути: `%APPDATA%\Konspekt\konspekt.log`

**НЕ** прикладывайте аудио, транскрипты или заметки. Они нам никогда не нужны для отладки.

## Проверить, что скачали именно нашу сборку

Konspekt пишет микрофон, слушает системный звук и перехватывает горячие
клавиши. Со стороны это ровно то же поведение, что у шпионской программы,
поэтому «мы проверили, всё чисто» от нас самих ничего не стоит. Проверьте
сами, это две команды.

Рядом с установщиком на странице релиза лежит файл `SHA256SUMS`. Откройте
его и сравните строку с тем, что посчитает Windows:

```
certutil -hashfile konspekt-0.9.0-setup.exe SHA256
```

Совпало — файл ровно тот, что мы собрали, и по дороге его не подменили.
Не совпало — не запускайте и напишите нам.

Каждый установщик проверяется на VirusTotal во время сборки, примерно
семьюдесятью антивирусами, ссылка на отчёт есть в описании релиза. Проверка
идёт на сборочном сервере до публикации, поэтому пропустить этот шаг втихую
нельзя.

Можно убедиться и в том, что файл собрали мы из нашего исходного кода, а не
кто-то посторонний:

```
gh attestation verify konspekt-0.9.0-setup.exe --repo lamver/konspekt
```

В команде указан `lamver/konspekt` — репозиторий с кодом, где идёт сборка, а
не этот, где публикуются релизы. Это не опечатка: подпись хранит место
сборки.

## Почему Windows ругается при установке

SmartScreen показывает «Windows защитила ваш компьютер» для любой
программы без сертификата подписи кода. Сертификат стоит денег и выдаётся
на организацию, у молодого проекта его обычно нет. Нажмите «Подробнее» и
«Выполнить в любом случае».

Антивирусы иногда ругаются на сборки PyInstaller сами по себе, безотносительно
содержимого: так упакованы и вполне честные программы, и вредоносные.
Именно поэтому мы публикуем контрольные суммы, отчёт VirusTotal и подпись
сборки: они проверяются, а обещания нет.

Если программа заблокирована совсем и не запускается (Defender сообщает об
ошибке 225), файл цел, ему просто не дают права запуститься. Сначала сверьте
контрольную сумму, и только если она совпала: «Защита от вирусов и угроз» →
«Журнал защиты» → найти Konspekt → «Действия» → «Разрешить на устройстве».
